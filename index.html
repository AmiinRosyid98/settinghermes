2 — Provider AI

Pilih Otak Hermes

cmd atau PowerShell
hermes setup
→ contoh tampilan wizard
? Pilih provider AI:
  ❯ Anthropic (Claude)
    OpenRouter
    Nous Portal

✓ Provider tersimpan ke config.yaml

Wizard interaktif akan tanya provider (Anthropic, OpenRouter, Nous Portal, dll.) dan model.

Sudah pakai Claude Code? Hermes otomatis mendeteksi kredensialnya lewat hermes auth status anthropic → anthropic: logged in. Tidak perlu isi API key terpisah.

Ganti pilihan kapan saja tanpa ulang wizard penuh: hermes model

3.1 — Telegram

Buat Bot lewat @BotFather

  1. Buka Telegram, chat ke @BotFather.
  2. Kirim /newbot, ikuti prompt (nama bebas, username unik & berakhiran bot).
  3. BotFather membalas dengan token API, contohnya:
    123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
Awas Token ini setara password bot. Jangan pernah disimpan permanen di chat AI mana pun. Kalau ragu ke-expose sekali, /revoke di BotFather dan buat baru.
3.2 — Telegram

Cari User ID Kamu

Bot butuh tahu User ID (angka) kamu — bukan username.

Chat ke @userinfobot di Telegram — dia langsung balas ID kamu.

Simpan angka ini, dipakai di langkah berikutnya.

3.3 — Telegram

Hubungkan Token ke Hermes

Opsi A — Wizard (disarankan)

hermes gateway setup
→ contoh wizard
? Platform: ❯ Telegram
? Bot token: ********
✓ tersimpan

Pilih Telegram, masukkan token + User ID — wizard yang menulis konfigurasinya.

Opsi B — Manual

.env
TELEGRAM_BOT_TOKEN=123456789:ABC...
TELEGRAM_ALLOWED_USERS=123456789

Edit langsung di ...\AppData\Local\hermes\.env

🔴 Gotcha nyata yang pernah kejadian Isi .env saja TIDAK CUKUP — gateway diam dengan log No messaging platforms enabled, kecuali platform-nya diaktifkan eksplisit:
config.yaml
gateway:
  platforms:
    - telegram

Bentuknya list, bukan dict. Opsi A menulis ini otomatis — kalau pakai Opsi B, jangan lupa baris ini.

3.4 — Telegram

Nyalakan Gateway

cmd atau PowerShell — foreground, Ctrl+C untuk stop
hermes gateway run
→ contoh output (log berjalan)
[gateway] Starting Hermes gateway...
[telegram] Connected to Telegram (polling mode)
[telegram] Listening for messages...

Kirim pesan apa saja ke bot-nya di Telegram untuk tes koneksi.

Bukan /start Kalau home channel sudah ke-set, /start sengaja diabaikan sebagai "platform ping", bukan pesan biasa. Tes pakai pesan biasa — misalnya "halo".
4 — Autostart Windows

Jalan Sendiri Tiap Laptop Nyala

cmd atau PowerShell
hermes gateway install --start-now --start-on-login

Di Windows ini mendaftarkan Scheduled Task (Hermes_Gateway) saat logon — bukan systemd (itu khusus Linux/WSL).

hermes gateway status → contoh output
✓ Scheduled Task registered: Hermes_Gateway
  Status: Ready
✓ Gateway process running (PID: xxxxx)
Dua gotcha Proses muncul sebagai python.exe di Task Manager — bukan hermes.exe. Dan ada celah startup ~20 detik: pesan yang masuk saat itu bisa terserap tapi tidak diproses.
